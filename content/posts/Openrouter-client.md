***Open Router PWA client***

New tool built today, completely vibe code on a mobile by Claude Code using Fable. Features a chat history and key storage, locally, and allows you to use all the models available via your openrouter api key. All storage is to your device. 

https://soulfiremage.github.io/openrouter-claude/

The concept I woke up with was, I'm on my phone, I wanted openrouter access, and didn't want to use sideloading or play store alternatives. And Russet has no reviews at time of writing. So, with merely a github repo (plus two settings on the repo) and Claude code app, an hour later, I have the client, with latex and markdown support. 

I've mixed feelings about vibe coding this way - the positive is I can get problems solved, quickly, with just a phone and the net. 

The negative is I've no real insite or learning about the code in question. Which for this app is not so important but imagine an enthusiast doing this for something with real teeth - a thing with access to a bank account or something else sensitive. 

Watch this space.
